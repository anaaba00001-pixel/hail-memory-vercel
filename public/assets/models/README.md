# مجسمات المجموعة
تحتوي هذه النسخة 34 ملف GLB مرفقًا بالمشروع، مع الخامات المضمنة في كل ملف. بعض النماذج المرخّصة من مصادر خارجية هُيئت للويب بتخفيض الخامات، أما الملفات المقدمة مباشرة للمتحف فحُفظت هندستها وخاماتها كما وردت ولم يُغيّر سوى أسمائها لتناسب مسارات الويب.
ملف credits.json يسجّل المصدر وصاحب العمل والترخيص وحجم النسخة الأصلية والنسخة المهيأة للويب.
بيانات العرض في assets/js/exhibits.js. تُحمّل ملفات GLB محليًا بمكتبة Three.js/GLTFLoader من assets/vendor.
