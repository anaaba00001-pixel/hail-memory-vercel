# مجسمات المجموعة
تحتوي هذه النسخة ثمانية ملفات GLB مرفقة بالمشروع، مع الخامات مضمنة. جرى تخفيض الخامات إلى حد أقصى 1024×1024 وإعادة ضغط الصور المعتمة بصيغة JPEG بجودة 92. الهندسة والمعلومات الأصلية محفوظة. النسخ الأصلية المرفوعة لم تتغير.
ملف credits.json يسجّل المصدر وصاحب العمل والترخيص وحجم النسخة الأصلية والنسخة المهيأة للويب.
بيانات العرض في assets/js/exhibits.js. تُحمّل ملفات GLB محليًا بمكتبة Three.js/GLTFLoader من assets/vendor.
الدلّة السعودية والفانوس والجنبية عروض مضمّنة من Sketchfab تحتاج الإنترنت؛ ملفاتها غير مرفقة. للانتقال إلى نسخة محلية: نزّل GLB من صفحة المصدر بعد استيفاء شروطه، وضعه هنا، واستبدل embed بمسار file في بيانات القطعة، وعدّل بيانات الترخيص إذا لزم.
